Политика конфиденциальности Shorts Studio

Обновлено: 23 ноября 2026 г.

Кто использует приложение

Shorts Studio — личный инструмент владельца YouTube-канала «Что, если…?». Приложение работает на компьютере владельца и используется только им для своего канала.

Какие данные Google используются

  • youtube.upload — загрузка собственных роликов владельца на его канал.
  • youtube.readonly — проверка, что ролик загружен, и получение ссылки на него.
  • yt-analytics.readonly — просмотры и удержание роликов канала для отчёта владельцу.

Как хранятся данные

  • Токен доступа Google хранится только на компьютере владельца, в закрытой папке приложения.
  • Статистика роликов сохраняется в локальные файлы владельца.
  • Данные не передаются, не продаются и не показываются третьим лицам, не используются для рекламы и не используются для обучения моделей ИИ.

Соответствие правилам Google

Использование и передача информации, полученной от Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Приложение использует YouTube API Services. Используя его, вы соглашаетесь с Условиями использования YouTube. Также действует Политика конфиденциальности Google.

Как отозвать доступ

Доступ можно отозвать в любой момент: myaccount.google.com/permissions. После этого локальный токен перестаёт работать; его файл можно удалить с компьютера.

Вопросы — через YouTube-канал «Что, если…?».

Privacy Policy (English)

Shorts Studio is a personal tool used only by the owner of the “Что, если…?” YouTube channel, on the owner’s own computer, for the owner’s own channel.

Google data used: youtube.upload (uploading the owner’s videos), youtube.readonly (confirming uploads and getting links), yt-analytics.readonly (views and retention of the channel’s videos for the owner’s reports).

Storage and sharing: the Google token and statistics are stored only locally on the owner’s computer. No data is shared, sold, shown to third parties, used for advertising, or used to train AI models.

Shorts Studio’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access: myaccount.google.com/permissions.
