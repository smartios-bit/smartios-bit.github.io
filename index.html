Shorts Studio

Инструмент канала «Что, если…?» — тёмные сценарии в анимации

Что это. Shorts Studio — личное приложение автора канала «Что, если…?». Оно загружает собственные анимационные ролики автора на его YouTube-канал через официальный YouTube Data API и показывает автору статистику этих роликов.

Приложение используется только владельцем канала для своего канала. Оно не предназначено для других пользователей и не собирает чужие данные.

What it is. Shorts Studio is a personal tool of the “Что, если…?” (“What if…?”) animation channel. It uploads the author’s own videos to the author’s YouTube channel via the official YouTube Data API and shows the author analytics for those videos. It is used only by the channel owner.
